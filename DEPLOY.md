# Развёртывание на Discloud.app 🚀

Discloud.app — хостинг, заточенный под Discord-ботов: он держит websocket-соединение
постоянно и автоматически перезапускает бота при падении. Не требует Docker или VPS.

> ⚠️ **Важно про токен.** Файл `.env` содержит `DISCORD_TOKEN`. Его **нельзя**
> загружать на GitHub и нельзя показывать в логах. Ниже `.env` попадает на хостинг
> только вручную, вместе с загрузкой проекта.

---

## Что подготовлено в репозитории

| Файл | Зачем |
|------|-------|
| `Discloud.config` | Конфиг Discloud: `APPTYPE=bot`, точка входа `bot.py`, RAM 512 МБ |
| `requirements.txt` | Зависимости (discord.py, python-dotenv) |
| `.gitignore` | Исключает `.env`, `venv/`, базу данных и бэкапы из git |

Никаких изменений в коде не требуется: пути к `data/` относительные, работают на любом сервере.

## Пошаговая инструкция

### 1. Зарегистрируйтесь и создайте приложение

1. Откройте **discloud.app** → Register (GitHub/Google/Discord).
2. Панель → **Create app** → выберите тип **Bot**.

### 2. Соберите zip для загрузки

В Discloud бот загружается архивом **.zip** (или прямо папкой через загрузчик).

На компьютере скопируйте проект и добавьте в архив **эти файлы**:

```
bot.py
config.py
database.py
requirements.txt
Discloud.config
cogs/
services/
utils/
.env              ← ВАЖНО: добавьте вручную, в git он не лежит
data/afk.sqlite3  ← ВАЖНО: чтобы сохранить историю (баллы, верификации)
```

Проверка перед запаковкой:

- Внутри zip должна быть структура, где `bot.py` лежит в корне (совпадает с `APPDIR=.`).
- `.env` и `data/afk.sqlite3` — добавить в архив вручную (Finder: перетащить в окно архива).

### 3. Загрузите на Discloud

- Панель → **Upload** → выберите ваш `.zip` → Start.
- (Альтернатива для разработчиков — API-загрузка через CLI, см. docs.discloud.app.)

### 4. Убедитесь, что бот работает

- В логах приложения вы должны увидеть:
  ```
  Бот запущен: Soul-bot (ID: ...)
  Команды синхронизированы...
  Инициализация завершена. Бот готов.
  ```
- Проверьте в Discord: таблица баллов создана, панель верификации закреплена, `/soul` отвечает.

### 5. Обновление в будущем

Изменяете код → снова собираете zip (с актуальными `.env` и `data/afk.sqlite3`) → **Upload**
поверх → приложение обновится. Старые данные не теряются, т.к. вы загружаете текущую БД.

## ⚠️ Про хранение данных (прочитайте!)

База данных — это файл `data/afk.sqlite3` + бэкапы в `data/backups/`.

- **Бэкапы бота** (раз в 24 ч) пишутся в папку приложения на хосте.
- Если бесплатный тариф Discloud **не гарантирует постоянный диск**, при удалении/пересоздании
  приложения файлы могут сброситься. Рекомендация:
  - Раз в несколько дней **скачивайте** `data/afk.sqlite3` и `data/backups/` через панель (Download) себе на компьютер.
  - При каждом загрузке нового zip **включайте актуальный** `data/afk.sqlite3` в архив.

## Инструкция для GitHub (по желанию)

GitHub хранит код, но не запускает процессы — на нём бот работать не будет.
Зато репозиторий полезен как резервная копия и для истории изменений.

```bash
cd /Users/muffin/Desktop/Discord-bot
git init
git add .
git commit -m "Инициализация: АФК-система, Soul-Coins, верификация"
# затем:
# 1) создайте пустой репозиторий на github.com
# 2) git remote add origin https://github.com/ВАШ_ЛОГИН/soul-bot.git
# 3) git push -u origin main
```

> В git попадает ТОЛЬКО код. `.env`, `venv/` и `data/` исключены через `.gitignore` —
> токен и данные игроков в репозиторий не попадут.
