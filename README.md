# 💤 Discord-бот для системы АФК

Бот для управления системой АФК (отсутствий) на небольшом Discord-сервере.
Игроки создают заявки через форму (Modal), модераторы принимают или отклоняют их
кнопками, бот выдаёт/снимает роль AFK автоматически и ведёт таблицу активных АФК.

## Возможности

**Игроки:**
- `/afk` и кнопка «💤 Создать заявку» — форма заявки (дата окончания + причина);
- `/my_afk` — посмотреть свою заявку;
- `/afk_cancel` — отменить заявку с подтверждением;
- DM-уведомления об одобрении, отклонении, отмене и завершении АФК.

**Модераторы:**
- кнопки «🟢 Принять» / «🔴 Отклонить» на сообщениях заявок (с причиной отказа);
- `/afk_status` — текущий список АФК;
- `/afk_admin` — меню: все заявки, активные АФК, обновление таблицы, очистка завершённых;
- `/afk_remove @user` — принудительно снять АФК;
- `/afk_list [status]` — список заявок с фильтром по статусу.

**Автоматика:**
- фоновая задача каждые `CHECK_INTERVAL_SECONDS` завершает истёкшие АФК (снимает роль,
  шлёт уведомление, обновляет таблицу и логи);
- таблица активных АФК и таблица Soul-Coins **автоматически пересобираются каждую
  минуту** (редактируют одно сообщение), подхватывая новых/вышедших игроков и смену никнеймов;
- восстановление после перезапуска: роли, таблица, панель, кнопки заявок.

**Soul-Coins 🪙:**
- динамическая таблица в чате «Таблица баллов» (Ник | Кол-во 🪙 | Под сокращением?)
  с кнопками «➕ Баллы» / «➖ Баллы»;
- начисление/списание: выбор игрока из списка → сумма → причина; логи в админ-чат «лог-баллов»;
- в конце месяца бот сам проверяет норму (`SOUL_COIN_NORM`, по умолчанию 60): не выполнившим
  снимает все роли и выдаёт единственную роль «сокращён»;
- предупреждения в админ-чат за `SOUL_COIN_WARNING_DAYS` дней до конца месяца;
- надёжность: WAL + busy_timeout, резервные копии БД каждые 24 ч и при выключении.

**Верификация новичков ✅:**
- закреплённое сообщение в канале «✅│верификация» с кнопкой «Верифицироваться»;
- анкета: статик, имя в игре, имя в жизни, чем занимается;
- после отправки выдаётся роль и никнейм `Verf. Имя в игре (Имя в жизни)`;
- анкета сохраняется в БД и пишется в админ-чат.

## Требования

- Python 3.11+ (рекомендуется 3.12/3.13)
- Доступ в интернет для установки зависимостей и работы с Discord API

## 1. Установка Python

Скачайте и установите Python с [python.org](https://www.python.org/downloads/)
(Windows/macOS) или через системный пакетный менеджер (Linux).

Проверьте версию:

```bash
python --version   # Windows
python3 --version  # Linux/macOS
```

## 2. Создание Discord Application

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications).
2. Нажмите **New Application**, введите имя и создайте приложение.

## 3. Создание Bot

1. В приложении перейдите в раздел **Bot** (слева).
2. Нажмите **Add Bot** → **Yes, do it!**.

## 4. Получение токена

1. В разделе **Bot** нажмите **Reset Token** → **Yes, do it!**.
2. Скопируйте токен (это ваш `DISCORD_TOKEN`). **Никому его не показывайте** —
   он хранится только в `.env` и никогда не должен попадать в код/README/git.

## 5. Включение необходимых Intents

В разделе **Bot** в блоке **Privileged Gateway Intents** включите:

- ✅ **SERVER MEMBERS INTENT**

Токен и интенты сохраните нажатием **Save Changes**.

## 6. Создание ролей

На сервере создайте роли:

- **AFK** — выдаётся игрокам при одобрении заявки;
- **Moderator** (или любая ваша роль модератора) — для обработки заявок.

Выдайте боту роль с правами выше роли AFK (чтобы он мог выдавать/снимать её),
а также права на отправку сообщений и управление сообщениями в нужных каналах.

## 7. Создание каналов

Рекомендуется создать отдельные каналы:

| Канал | Назначение |
|---|---|
| `💤・afk` | панель «Создать заявку» для всех |
| `🛡・afk-reviews` | новые заявки для модераторов (скрыть от игроков) |
| `📋・afk-status` | таблица активных АФК |
| `📜・afk-logs` | логи событий |

## 8. Получение ID каналов и ролей

Включите режим разработчика в Discord: **Настройки → Дополнительно → Режим разработчика**.

Далее ПКМ по нужному элементу → **Копировать ID**:

- сервер: ПКМ по иконке сервера → «Копировать ID сервера» (`GUILD_ID`);
- канал: ПКМ по каналу → «Копировать ID канала»;
- роль: Настройки сервера → Роли → ПКМ по роли → «Копировать ID роли».

## 9. Создание `.env`

Скопируйте пример конфигурации и заполните реальными значениями:

```bash
cp .env.example .env
```

```env
DISCORD_TOKEN=YOUR_BOT_TOKEN
GUILD_ID=YOUR_SERVER_ID

AFK_CHANNEL_ID=YOUR_AFK_CHANNEL_ID
AFK_REVIEW_CHANNEL_ID=YOUR_REVIEW_CHANNEL_ID
AFK_LOG_CHANNEL_ID=YOUR_LOG_CHANNEL_ID
AFK_STATUS_CHANNEL_ID=YOUR_STATUS_CHANNEL_ID

AFK_ROLE_ID=YOUR_AFK_ROLE_ID
AFK_REVIEW_ROLE_IDS=123456789,987654321
ADMIN_ROLE_ID=
MODERATOR_ROLE_ID=

SOUL_COIN_TABLE_CHANNEL_ID=YOUR_TABLE_CHANNEL_ID
SOUL_COIN_LOG_CHANNEL_ID=YOUR_LOG_CHANNEL_ID
LEADER_ROLE_ID=YOUR_LEADER_ROLE_ID
SOUL_COIN_NORM=60
SOUL_COIN_REDUCED_ROLE_ID=YOUR_REDUCED_ROLE_ID
SOUL_COIN_WARNING_DAYS=7

VERIFY_CHANNEL_ID=YOUR_VERIFY_CHANNEL_ID
VERIFY_ROLE_ID=YOUR_VERIFY_ROLE_ID
VERIFY_LOG_CHANNEL_ID=YOUR_ADMIN_LOG_CHANNEL_ID
VERIFY_NICK_PREFIX=Verf

TIMEZONE=Europe/Berlin
MAX_AFK_DAYS=30
MIN_AFK_MINUTES=30
CHECK_INTERVAL_SECONDS=60
SYNC_GLOBALLY=false
```

Описание ключей:

- `DISCORD_TOKEN` — токен бота (п. 4).
- `GUILD_ID` — ID сервера.
- `AFK_CHANNEL_ID` — канал с панелью «Создать заявку».
- `AFK_REVIEW_CHANNEL_ID` — канал, куда падают заявки для модераторов.
- `AFK_LOG_CHANNEL_ID` — канал логов.
- `AFK_STATUS_CHANNEL_ID` — канал таблицы активных АФК.
- `AFK_ROLE_ID` — роль AFK, выдаваемая при одобрении.
- `AFK_REVIEW_ROLE_IDS` — роли с правом принимать/отклонять заявки (через запятую).
- `ADMIN_ROLE_ID`, `MODERATOR_ROLE_ID` — опциональные дополнительные роли.
- `TIMEZONE` — часовой пояс сервера (Iana-имя, напр. `Europe/Berlin`, `Europe/Moscow`).
- `MAX_AFK_DAYS` — максимальный срок АФК в днях.
- `MIN_AFK_MINUTES` — минимальный срок АФК в минутах.
- `CHECK_INTERVAL_SECONDS` — как часто проверяются завершённые АФК.
- `SYNC_GLOBALLY` — `false` (по умолчанию): команды только на вашем сервере;
  `true`: глобальная регистрация команд.

Soul-Coins:

- `SOUL_COIN_TABLE_CHANNEL_ID` — канал «Таблица баллов»: бот держит в нём
  одно сообщение с таблицей и кнопками «➕/➖ Баллы».
- `SOUL_COIN_LOG_CHANNEL_ID` — админ-чат «лог-баллов»: логи начислений,
  предупреждения и отчёт по итогам месяца.
- `LEADER_ROLE_ID` — роль Leader; участники с ней (и с `ADMIN_ROLE_ID`)
  не попадают в таблицу баллов.
- `SOUL_COIN_NORM` — минимальная норма баллов в месяц (по умолчанию `60`).
- `SOUL_COIN_REDUCED_ROLE_ID` — единственная роль, которая выдаётся игроку,
  не выполнившему норму (у него снимаются все остальные роли).
- `SOUL_COIN_WARNING_DAYS` — за сколько дней до конца месяца слать
  предупреждения о невыполненной норме.

Верификация:

- `VERIFY_CHANNEL_ID` — канал «✅│верификация»: бот держит в нём закреплённое
  сообщение с кнопкой «Верифицироваться».
- `VERIFY_ROLE_ID` — роль «✅ Верифицирован», выдаваемая после анкеты.
- `VERIFY_LOG_CHANNEL_ID` — админ-чат, куда пишется лог каждой верификации.
- `VERIFY_NICK_PREFIX` — префикс в никнейме новичка (по умолчанию `Verf`):
  `Verf. Имя в игре (Имя в жизни)`.

## 12. Первый запуск

1. Добавьте бота на сервер (URL для приглашения создаётся в Developer Portal →
   **OAuth2 → URL Generator**, scope `bot` + `applications.commands`,
   нужные права).
2. Запустите `python bot.py`.
3. В консоли должно появиться «Бот запущен», «Команды синхронизированы…».
4. На канале `AFK_CHANNEL_ID` появится панель «💤 Система АФК» с кнопками,
   на канале `AFK_STATUS_CHANNEL_ID` — таблица активных АФК.
5. Slash-команды появятся сразу (guild sync). Если команды не видны —
   перезапустите Discord или подождите до минуты.

## 13. Soul-Coins 🪙

Система ежемесячных баллов для игроков сервера. В таблицу попадают все участники,
кроме ботов и участников с ролями `LEADER_ROLE_ID` / `ADMIN_ROLE_ID`. Каждый должен
набирать не меньше `SOUL_COIN_NORM` (по умолчанию 60) баллов в месяц.

**Как это работает:**

1. Бот создаёт в канале «Таблица баллов» одно сообщение-таблицу (Ник | 🪙 | Сокращение)
   с кнопками **➕ Баллы** / **➖ Баллы**. Кнопки доступны модераторам.
2. Модератор нажимает кнопку, выбирает игрока из списка, вводит сумму и причину.
   Каждое действие логируется в админ-чат «лог-баллов».
3. За `SOUL_COIN_WARNING_DAYS` дней до конца месяца бот постит в «лог-баллов»
   предупреждение со списком тех, кто не дотягивает до нормы.
4. В конце месяца бот подводит итоги: не выполнившим норму **снимаются все снимаемые
   роли** и выдаётся единственная роль «сокращён» (`SOUL_COIN_REDUCED_ROLE_ID`).
   В «лог-баллов» отправляется отчёт со списком. Балансы обнуляются на новый месяц.

**Команды:**

- `/soul` — игрок видит свой баланс и статус;
- `/soul_admin` (модераторы) — меню: обновить таблицу, проверка нормы;
- `/soul_logs @user` (модераторы) — история начислений игрока.

> Проверка нормы запускается автоматически при смене месяца (в т.ч. если бот был
> оффлайн — на старте он закрывает пропущенный месяц). Кнопка «Проверка нормы»
> в `/soul_admin` подводит итоги, если месяц действительно закончился.

## 14. Верификация новичков ✅

Новичок, который только попал на сервер, проходит анкету, чтобы получить роль
и никнейм в принятом на сервере формате.

**Как это работает:**

1. Бот держит в канале «✅│верификация» закреплённое сообщение с кнопкой
   **«Верифицироваться»**.
2. Игрок нажимает кнопку и заполняет анкету: статик, имя в игре (только имя,
   без фамилии), имя в жизни, чем занимается.
3. После отправки бот выдаёт роль `VERIFY_ROLE_ID` и ставит никнейм
   `Verf. Имя в игре (Имя в жизни)` (например `Verf. Angel (Артём)`).
   Длинные имена автоматически ужимаются под лимит никнейма (32 символа).
4. Анкета сохраняется в БД и пишется в админ-чат (`VERIFY_LOG_CHANNEL_ID`).

**Команды:**

- `/verify_setup` (модераторы) — создать/обновить закреплённую панель верификации;
- `/verify_info @user` (модераторы) — посмотреть анкету игрока.

## 15. Настройка прав

Боту нужны права:

- отправлять сообщения и использовать кнопки/модальные окна;
- управлять сообщениями (чтобы редактировать заявки и таблицу);
- управлять ролями (выдавать/снимать роль AFK);
- отправлять личные сообщения игрокам.

Выдайте боту роль выше роли AFK на сервере.

## 16. Решение распространённых проблем

| Проблема | Решение |
|---|---|
| `DISCORD_TOKEN не задан` | Проверьте, что `.env` создан из `.env.example` и заполнен |
| `403 Forbidden` при выдаче роли | Роль бота стоит ниже роли AFK — поднимите её выше |
| Не видны slash-команды | Перезапустите Discord; проверьте `GUILD_ID`; `SYNC_GLOBALLY=false` |
| Не приходит DM игроку | У игрока отключены личные сообщения — бот логирует и продолжает работу |
| `SERVER MEMBERS INTENT` не работает | Включите **SERVER MEMBERS INTENT** в Developer Portal |
| Бот не создаёт панель/таблицу | Проверьте `AFK_CHANNEL_ID` / `AFK_STATUS_CHANNEL_ID` и права бота в канале |
| Не регистрируются команды | Проверьте токен и что приложение имеет `applications.commands` scope |

## Замечания

- Все даты хранятся в БД в UTC, пользователям показываются в часовом поясе сервера
  (`TIMEZONE`) и дополнительно через Discord timestamp (локальное время игрока).
- Кнопки одобрения/отклонения проверяют роли **при нажатии**, а не только при отрисовке.
- Переходы статусов защищены атомарными UPDATE — две кнопки «Принять», нажатые
  одновременно, обработать заявку не смогут.
- После перезапуска бот восстанавливает панель, таблицу, кнопки заявок и роли,
  а также немедленно завершает уже истёкшие АФК.

**Надёжность данных:**

- SQLite в режиме WAL (`busy_timeout=10 c`): при перезапуске, выключении сервера
  или потере интернета данные не теряются; конкурентные запросы ждут, а не падают.
- Начисление баллов и запись в лог выполняются одной атомарной транзакцией.
- Резервные копии `data/backups/` — раз в 24 часа и при корректном выключении бота
  (хранятся последние 7 копий).
- При выключении WAL сводится в основной файл (`wal_checkpoint(TRUNCATE)`).
